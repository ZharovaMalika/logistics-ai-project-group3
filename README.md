# logistics-ai-project-group3
AI-Driven Smart Logistics &amp; Supply Chain Intelligence System using Python and Power BI

## Project Overview
This repository contains our final graduation project focused on integrating Artificial Intelligence (AI) and Machine Learning models to optimize supply chain operations and shipment pricing. By analyzing historical logistics data, the system predicts transportation costs, forecasts inventory demand, identifies operational risk and bottlenecks, and provides end-to-end transparency. 

The project connects back-end data engineering and predictive modeling in Python with an interactive, multi-page strategic dashboard built in Microsoft Power BI.

## Tools and Libraries Used
* Programming Language: Python 3
* Data Processing & Analytics: Pandas, NumPy
* Data Visualization: Matplotlib, Seaborn
* Machine Learning & AI Modules: Scikit-Learn (Linear Regression, KMeans Clustering, Random Forest / XGBoost, and Time-Series components for Demand Forecasting)
* Business Intelligence: Microsoft Power BI Desktop

## Repository Structure
The project files are systematically structured into the mandatory directories as follows:
* /data — Contains the raw and preprocessed logistics and supply chain datasets.
* /notebook — Contains the primary Jupyter Notebook (`Supply_Chain_Shipment_Pricing.ipynb`) implementing data cleaning, feature engineering, clustering, and predictive algorithms.
* /report — Contains the final written analytical report in PDF format.
* /dashboard — Contains high-quality exported screenshots of the 8 distinct analytical pages of our Power BI ecosystem.
* /presentation — Contains the final presentation slide deck (PPTX/PDF) used for the defense.
